# Proyecto Laser Tag

La idea es poder dibujar de manera virtual mediante el trackeo de la posición del láser, el cual se proyecta a un lienzo “invisible” (es un lienzo en negro, aunque con los proyectores de la u igual se notan los negros) y para trackear la posición se una una cámara la cual apunta hacia la misma proyección. Todo esto se procesa dentro de una aplicación web basada en p5.js (se ejecuta de manera local (vscode), por lo que no necesita acceso a internet.
